## Section 3: Emergency Procedures  
  
### Automatic Flight Control Malfunction (Autopilot, ESP, Trim, Flaps)  
  
- [ ] AP DISC Button - PRESS AND HOLD  
- [ ] AP SERVO (A1), PITCH TRIM (B1), ROLL TRIM (B2), FLAPS (D3) CBs - PULL, AS REQUIRED  
- [ ] AP DISC Button - RELEASE  
- [ ] Land as soon as practicable.  
  
### Cabin Fire In Flight  
  
- [ ] BAT 1, ALT 1, and ALT 2 Switches - OFF  
- [ ] Fire Extinguisher - ACTIVATE AS REQUIRED  
- [ ] All other switches - OFF  
- [ ] Land as soon as possible.  
- [ ] If setting BAT/ALT off eliminated source of fire or fumes and airplane is in night or IFR conditions:  
    - [ ] Airflow Selector - OFF  
    - [ ] BAT 1, ALT 1, and ALT 2 Switches - ON  
    - [ ] Required Systems - ACTIVATE ONE AT A TIME  
    - [ ] Temperature Selector - COLD  
    - [ ] Vent Selector - FEET/PANEL/DEFROST POSITION  
    - [ ] Airflow Selector - SET AIRFLOW TO MAXIMUM  
    - [ ] Panel Vents - OPEN  
    - [ ] Land as soon as possible.  
  
### CAPS Deployment  
  
- [ ] Activation Handle - PULL DOWN STEADILY WITH BOTH HANDS  
- [ ] Mixture - CUTOFF  
- [ ] Fuel Selector - OFF  
- [ ] Fuel Pump - OFF  
- [ ] BAT/ALT Switches - OFF (after completing any necessary radio communications)  
- [ ] Engine Knob - OFF  
- [ ] ELT - VERIFY ON  
- [ ] Loose Items - SECURE  
- [ ] Seat Belts - TIGHTEN  
- [ ] Assume emergency landing body position.  
- [ ] After the aircraft comes to a complete stop, evacuate quickly and move upwind well clear of both aircraft and parachute.  
  
### Ditching  
  
- [ ] Radio - TRANSMIT (121.5 MHz) MAYDAY WITH LOCATION AND INTENTIONS  
- [ ] Transponder - SQUAWK 7700  
- [ ] CAPS - ACTIVATE  
- [ ] Airplane - EVACUATE  
- [ ] Flotation Devices (if available) - INFLATE WHEN CLEAR OF AIRPLANE  
  
### Emergency Descent  
  
- [ ] AP DISC Button - PRESS AND RELEASE  
- [ ] Power Lever - IDLE  
- [ ] Mixture - RICH (AS REQ'D)  
- [ ] Airspeed - INCREASE TO VNE  
  
### Emergency Engine Shutdown On Ground  
  
- [ ] Mixture - CUTOFF  
- [ ] Fuel Pump - OFF  
- [ ] Fuel Selector - OFF  
- [ ] Engine Knob - OFF  
- [ ] BAT/ALT Switches - OFF  
  
### Emergency Ground Egress  
  
- [ ] Mixture - CUTOFF  
- [ ] Fuel Pump - OFF  
- [ ] BAT 1 and BAT 2 Switches - OFF  
- [ ] Parking Brake - SET  
- [ ] Egress aircraft.  
  
### Emergency Landing w/o Power  
  
- [ ] Pitch for best glide.  
- [ ] Turn towards nearest practical landing site.  
- [ ] Radio - TRANSMIT (ATC OR 121.5 MHz) MAYDAY WITH LOCATION AND INTENTIONS  
- [ ] Transponder - SQUAWK 7700  
- [ ] Mixture - CUTOFF  
- [ ] Fuel Pump - OFF  
- [ ] Fuel Selector - OFF  
- [ ] Engine Knob - OFF  
- [ ] If landing site is improved:  
    - [ ] Flaps - AS REQUIRED  
    - [ ] Seat Belt(s) - SECURED  
    - [ ] Touchdown - NORMAL TECHNIQUE  
- [ ] After landing:  
    - [ ] BAT 1 and BAT 2 Switches - OFF  
    - [ ] Evacuate airplane.  
  
### Engine Failure In Flight  
  
- [ ] Fuel Pump - BOOST  
- [ ] Fuel Selector - SWITCH TANKS  
- [ ] Engine Knob - CHECK L, R, THEN BOTH (AS REQ'D)  
- [ ] Alternate Induction Air - ON  
- [ ] Power Lever - HALF OPEN  
- [ ] Mixture - IDLE CUTOFF THEN SLOWLY ADVANCE UNTIL ENGINE STARTS  
- [ ] Starter (Propeller not windmilling) - ENGAGE  
- [ ] Mixture - TOP OF GREEN ARC  
- [ ] If engine start is successful:  
    - [ ] CHTs and Oil Temperature - WARM ENGINE AT PARTIAL POWER UNTIL IN GREEN ARC  
    - [ ] Land as soon as practicable.  
- [ ] If engine does not start:  
    - [ ] Perform Emergency Landing w/o Power Checklist.  
  
### Engine Failure On Takeoff - Low Altitude  
  
- [ ] Best Glide or Landing Speed - ESTABLISH  
- [ ] Fuel Selector - OFF  
- [ ] Flaps - AS REQUIRED  
- [ ] Land straight ahead.  
- [ ] If time permits:  
    - [ ] Power Lever - IDLE  
    - [ ] Mixture - CUTOFF  
    - [ ] Fuel Pump - OFF  
    - [ ] Seat Belts - SECURED  
    - [ ] BAT/ALT Switches - OFF  
  
### Engine Fire During Start  
  
- [ ] Mixture - CUTOFF  
- [ ] Fuel Pump - OFF  
- [ ] Fuel Selector - OFF  
- [ ] Power Lever - FORWARD  
- [ ] Starter - ENGAGE  
- [ ] If flames persist:  
    - [ ] Evacuate aircraft.  
  
### Engine Fire In Flight  
  
- [ ] Mixture - CUTOFF  
- [ ] Fuel Pump - OFF  
- [ ] Fuel Selector - OFF  
- [ ] Airflow Selector - OFF  
- [ ] Power Lever - IDLE  
- [ ] Engine Knob - OFF  
- [ ] Perform Emergency Landing w/o Power Checklist.  
  
### Engine Partial Power Loss  
  
- [ ] Air Conditioner (if installed) - OFF  
- [ ] Fuel Pump - BOOST  
- [ ] Fuel Selector - SWITCH TANKS, LEAVE COVER OPEN  
- [ ] Mixture - CHECK APPROPRIATE FOR FLIGHT CONDITIONS  
- [ ] Power Lever - SWEEP  
- [ ] Alternate Induction Air - ON  
- [ ] Engine Knob - CHECK L, R, THEN BOTH AS REQ'D  
- [ ] Land as soon as practicable.  
  
### Ice Protection System Failure/ Excessive Ice Accumulation  
  
- [ ] ICE PROTECT 1 (A4) and 2 (B4) Circuit Breakers - SET  
- [ ] IPS Tank Select - SWITCH TO FULLER TANK  
- [ ] W/S Push-Button - PRESS  
    - [ ] Repeat operation of windshield pump to verify metering pumps are primed properly as evidenced by deicing fluid exiting windshield nozzles.  
- [ ] ICE PROTECT Mode Switch - VERIFY HIGH  
- [ ] BKUP Switch - ON  
- [ ] If determined windshield pump is not priming:  
    - [ ] Exit icing conditions immediately.  
    - [ ] Airspeed - 95 KIAS OR GREATER  
        - [ ] Maintain a minimum airspeed of 95 KIAS or higher to stay above pre-stall buffet. If unable to maintain this airspeed, allow altitude to decrease in order to maintain 95 KIAS.  
    - [ ] Minimum Approach Speed w/ Residual Ice (Flaps 50%) - 88 KIAS  
    - [ ] Flaps - MINIMUM REQUIRED  
  
### Inadvertent Spin Entry  
  
- [ ] CAPS - ACTIVATE  
  
### Landing Without Elevator Control  
  
- [ ] Flaps - 50%  
- [ ] Trim - 80 KIAS  
- [ ] Power - AS REQUIRED FOR GLIDE ANGLE  
  
### Power Lever Linkage Failure  
  
- [ ] Power Lever Movement - VERIFY  
- [ ] Power - SET IF ABLE  
- [ ] Flaps - SET IF NEEDED  
- [ ] Mixture - AS REQUIRED (FULL RICH TO CUTOFF)  
- [ ] Land as soon as possible.  
  
### Propeller Governor Failure  
  
- [ ] Power Lever - REDUCE TO MINIMUM NECESSARY FOR SUSTAINED FLIGHT  
- [ ] Airspeed - REDUCE TO 85-90 KIAS  
- [ ] Land as soon as practicable.  
  
### Rejected Takeoff  
  
- [ ] Brakes - MAXIMUM PILOT EFFORT W/O SKIDDING  
- [ ] Power Lever - IDLE  
- [ ] After airplane comes to a complete stop:  
    - [ ] Brakes - COOL DOWN  
  
### Smoke and Fume Elimination  
  
- [ ] Air Conditioner - RECIRC DISABLED  
- [ ] Temperature Selector - COLD  
- [ ] Vent Selector - FEET/PANEL/DEFROST  
- [ ] Airflow Selector - MAXIMUM  
- [ ] Fuel Selector - MANUAL MODE  
- [ ] If source of smoke and fume is firewall forward:  
    - [ ] Airflow Selector - OFF  
- [ ] Panel Vents - OPEN  
- [ ] Supplemental Oxygen (if installed):  
    - [ ] Oxygen Masks or Cannulas - DON  
    - [ ] OXY Switch - ON  
    - [ ] Oxygen Flow Rate - MAXIMUM  
- [ ] Land as soon as possible.  
  
### Wing Fire In Flight  
  
- [ ] Probe Heat - OFF  
- [ ] NAV LIGHTS (D5) Circuit Breaker - PULL  
- [ ] Landing Lights (LAND Switch) - OFF  
- [ ] Strobe Lights (STRB Switch) - OFF  
- [ ] AP DISC Button - PRESS AND HOLD  
- [ ] If possible, side slip to keep flames away from fuel tank and cabin.  
- [ ] Land as soon as possible.  
  
### AOA OVERHEAT Warning  
  
- [ ] Probe Heat - OFF  
- [ ] Icing Conditions - AVOID/EXIT  
  
### APPROACH SPEED Warning  
  
- [ ] Approach - GO-AROUND  
  
### AUTO DESCENT Warning  
  
- [ ] Situation - ASSESS  
- [ ] If hypoxia is suspected and oxygen is installed:  
    - [ ] Oxygen Masks or Cannulas - DON  
    - [ ] Oxygen System (OXY Switch) - ON  
    - [ ] Oxygen Flow Rate - MAXIMUM  
- [ ] If pilot is fit and autopilot has not begun descent:  
    - [ ] Perform one or more of the following actions to reset hypoxia alert, as appropriate:  
        - [ ] Press softkeys on GDUs, GTCs, or GMC 707.  
        - [ ] Press GTC Knob(s).  
        - [ ] Acknowledge prompt(s) on GTC touchscreen(s).  
- [ ] If pilot is fit, autopilot is engaged, and a descent is initiated:  
    - [ ] AP DISC - PRESS  
    - [ ] Selected Altitude - RESET TO DESIRED  
    - [ ] Autopilot - ENGAGE  
  
### CHT Warning  
  
- [ ] If on ground:  
    - [ ] Power Lever - REDUCE TO IDLE  
    - [ ] Mixture - FULL RICH  
    - [ ] Annunciations and Engine Temperatures - MONITOR  
    - [ ] If Warning annunciation is still illuminated, and temperatures not decreasing:  
        - [ ] Shutdown engine.  
        - [ ] Do not dispatch.  
- [ ] If in flight:  
    - [ ] Power Lever - REDUCE  
    - [ ] Mixture - ADJUST FUEL FLOW TO TOP OF GREEN ARC  
    - [ ] Airspeed - INCREASE  
    - [ ] Annunciations and Engine Temperatures - MONITOR  
    - [ ] If Warning annunciation is still illuminated:  
        - [ ] Power Lever - MINIMUM REQUIRED  
        - [ ] Engine Instruments - MONITOR  
        - [ ] If Warning is extinguished and Caution is illuminated:  
            - [ ] Land as soon as practicable.  
        - [ ] If Warning annunciation remains illuminated:  
            - [ ] Land as soon as possible.  
  
### CO LEVEL HIGH Warning  
  
- [ ] Air Conditioner - RECIRC DISABLED  
- [ ] Temperature Selector - COLD  
- [ ] Vent Selector - FEET/PANEL/DEFROST  
- [ ] Airflow Selector - MAXIMUM  
- [ ] Panel Vents - OPEN  
- [ ] If message does not extinguish:  
    - [ ] Supplemental Oxygen (if available):  
        - [ ] Oxygen Masks or Cannulas - DON  
        - [ ] Oxygen System (OXY Switch) - ON  
        - [ ] Oxygen Flow Rate - MAXIMUM  
    - [ ] Land as soon as possible.  
  
### ESSENTIAL BUS VOLTS Warning  
  
- [ ] Essential Bus Voltage (ESS Bus V) - CHECK  
- [ ] If Essential Bus Voltage is greater than 32 Volts:  
    - [ ] Main Bus 1 and Main Bus 2 Voltages - CHECK  
    - [ ] If Main Bus 1 voltage is high:  
        - [ ] ALT 1 (D11) Circuit Breaker - SET  
        - [ ] ALT 1 Switch - CYCLE  
    - [ ] If Main Bus 2 voltage is high:  
        - [ ] ALT 2 (B5) Circuit Breaker - SET  
        - [ ] ALT 2 Switch - CYCLE  
- [ ] If unable to restore at least one alternator:  
    - [ ] Non-Essential Loads - REDUCE  
    - [ ] If flight conditions permit, consider shedding:  
        - [ ] Air Conditioning - OFF  
        - [ ] Cabin Fan - OFF  
        - [ ] Landing Lights (LAND Switch) - OFF  
        - [ ] Probe Heat - OFF  
        - [ ] Strobe Lights (STRB Switch) - OFF  
        - [ ] COM 2/AUDIO PANL (C12) Circuit Breaker - PULL  
        - [ ] YAW SERVO (C1) Circuit Breaker - PULL  
- [ ] Land as soon as practicable.  
  
### FLAPS ICE Warning  
  
- [ ] Flaps - SET UP OR 50%  
  
### FUEL FLOW Warning  
  
- [ ] If on ground:  
    - [ ] Correct prior to flight.  
- [ ] If in flight:  
    - [ ] Mixture - ADJUST  
        - [ ] Adjust engine operation to correct condition. Check engine instruments to verify HIGH FLOW Warning is not erroneous, i.e. abnormal engine temperatures or engine roughness after mixture adjustment.  
    - [ ] If FUEL FLOW Warning does not extinguish:  
        - [ ] Land as soon as practicable.  
  
### FUEL IMBALANCE Warning  
  
- [ ] Fuel Quantity Gauges - CHECK  
- [ ] Fuel Selector - SELECT FULLER TANK  
  
### FUEL LOW LEFT Warning  
  
- [ ] Fuel Quantity Gauges - CHECK  
- [ ] Fuel Selector - RIGHT TANK, LEAVE COVER OPEN  
  
### FUEL LOW RIGHT Warning  
  
- [ ] Fuel Quantity Gauges - CHECK  
- [ ] Fuel Selector - LEFT TANK, LEAVE COVER OPEN  
  
### FUEL LOW TOTAL Warning  
  
- [ ] Fuel Quantity Gauges - CHECK  
- [ ] Totalized Fuel Quantity - CHECK  
- [ ] If totalized fuel quantity differs significantly from sensed quantity:  
    - [ ] Initial Fuel Value - VERIFY AND CORRECT  
- [ ] If message persists:  
    - [ ] Land as soon as practicable.  
  
### IPS CONTROL FAIL Warning  
  
- [ ] Icing Conditions - AVOID/EXIT  
  
### IPS FLUID LOW Warning  
  
- [ ] Icing Conditions - AVOID/EXIT  
  
### IPS QUANTITY FAIL Warning  
  
- [ ] Icing Conditions - AVOID/EXIT  
  
### MAIN BUS 1 VOLTS Warning  
  
- [ ] ALT 1 Switch - CYCLE  
- [ ] M Bus 1 Voltage (M1) - CHECK  
- [ ] If M Bus 1 Voltage is greater than 32 volts:  
    - [ ] ALT 1 Switch - OFF  
    - [ ] Perform ALTERNATOR 1 CURRENT Caution Checklist (do not reset alternator).  
  
### MAIN BUS 2 VOLTS Warning  
  
- [ ] If MAIN BUS 1 VOLTS Warning is also asserted:  
    - [ ] Perform MAIN BUS 1 VOLTS Warning Checklist.  
- [ ] If MAIN BUS 1 VOLTS Warning is not also asserted:  
    - [ ] ALT 1 Switch - OFF  
    - [ ] Main Bus 2 Voltage - CHECK  
    - [ ] ALT 1 Switch - ON  
    - [ ] Main Bus 1 Voltage - CHECK  
    - [ ] Main Bus 2 Voltage - CHECK  
- [ ] If Main Bus 2 Voltage is greater than 32 volts with ALT 1 off:  
    - [ ] ALT 2 Switch - CYCLE  
    - [ ] Main Bus 2 Voltage - CHECK  
    - [ ] If Main Bus 2 Voltage remains greater than 32 volts:  
        - [ ] ALT 2 Switch - OFF  
  
### OIL PRESSURE Warning  
  
- [ ] Oil Pressure Gauge - CHECK  
- [ ] If pressure low / high:  
    - [ ] Power - REDUCE TO MINIMUM FOR SUSTAINED FLIGHT  
    - [ ] Land as soon as possible.  
        - [ ] Prepare for potential engine failure.  
  
### OIL TEMP Warning  
  
- [ ] Power - REDUCE  
- [ ] Airspeed - INCREASE  
- [ ] Mixture - AS REQUIRED  
- [ ] Oil Temperature Gauge - MONITOR  
- [ ] If message persists:  
    - [ ] Land as soon as possible.  
  
### OXYGEN FAULT Warning  
  
- [ ] Oxygen Flow Rate - CHECK  
- [ ] If no flow:  
    - [ ] Initiate Emergency Descent to below 12,500 ft:  
        - [ ] AP DISC Button - PRESS AND RELEASE  
        - [ ] Power Lever - IDLE  
        - [ ] Mixture - AS REQUIRED  
        - [ ] Airspeed - VNE  
    - [ ] Below 12,500 ft:  
        - [ ] Oxygen System (OXY Switch) - OFF  
        - [ ] Flight - CONTINUE  
- [ ] If flow is normal:  
    - [ ] Oxygen Flow Rate - MONITOR  
    - [ ] Initiate Normal Descent as soon as practical.  
    - [ ] Below 12,500 ft:  
        - [ ] Oxygen System (OXY Switch) - OFF  
        - [ ] Flight - CONTINUE  
  
### OXYGEN QTY LOW Warning  
  
- [ ] Oxygen Pressure and Flow Rate - CHECK  
- [ ] Initiate Normal Descent (non-emergency) below 12,500 ft.  
- [ ] Oxygen Flow Rate - MONITOR  
- [ ] Below 12,500 ft:  
    - [ ] Flight - CONTINUE  
  
### OXYGEN REQUIRED Warning  
  
- [ ] Oxygen System (OXY Switch) - ON  
- [ ] Oxygen Mask/Canula - DON  
- [ ] Oxygen Flow Rate - SET AND MONITOR  
  
### RPM Warning  
  
- [ ] Tachometer - CHECK  
- [ ] If engine speed normal:  
    - [ ] If on ground - CORRECT PRIOR TO FLIGHT  
    - [ ] If in flight - CONTINUE, MONITOR  
- [ ] If engine speed high:  
    - [ ] Perform Propeller Governor Failure Checklist.  
- [ ] Oil Pressure Gauge - CHECK  
  
### SPIN SPIN SPIN Warning  
  
- [ ] CAPS - ACTIVATE  
  
### STALL Warning  
  
- [ ] Angle of Attack - REDUCE  
- [ ] Power Lever - FULL FORWARD  
  
### STALL WARNING FAIL Warning  
  
- [ ] Airspeed - MAINTAIN ABOVE 1.3VS  
- [ ] Avoid stalls, low airspeed, and uncoordinated or abrupt control inputs.  
- [ ] Land as soon as practicable.  
  
### STARTER ENGAGED Warning  
  
- [ ] If on ground:  
    - [ ] Engine Knob - OFF  
    - [ ] Wait 1 minute before next start attempt.  
    - [ ] If starter does not disengage (stuck button, relay, or solenoid failure):  
        - [ ] BAT 1 Switch - OFF  
        - [ ] Mixture - CUTOFF  
        - [ ] Fuel Pump - OFF  
        - [ ] STARTER (D1) Circuit Breaker - PULL  
- [ ] If in flight:  
    - [ ] STARTER (D1) Circuit Breaker - PULL  
    - [ ] Flight - CONTINUE  
        - [ ] Engine start will not be available at destination.  
  
## Section 3A: Abnormal Procedures  
  
### Fuel Valve Malfunction  
  
- [ ] If manual fuel selector operation is difficult:  
    - [ ] FUEL VALVE Circuit Breaker (C3) - PULL  
    - [ ] Fuel Selector - LEFT OR RIGHT (AS REQ'D)  
    - [ ] If difficult operation persists:  
        - [ ] Fuel Selector - LEAVE COVER OPEN FOR MANUAL OPERATION  
    - [ ] If condition is resolved:  
        - [ ] FUEL VALVE Circuit Breaker (C3) - SET  
        - [ ] Fuel Selector - CLOSE COVER FOR AUTOMATIC OPERATION  
  
### Brake Failure During Taxi  
  
- [ ] Engine Power - AS REQUIRED  
- [ ] Directional Control - MAINTAIN WITH RUDDER  
- [ ] Brake Pedal(s) - PUMP  
- [ ] If directional control cannot be maintained:  
    - [ ] Engine Knob - OFF  
  
### Communications Failure  
  
- [ ] Switches and Controls - CHECK  
- [ ] Frequency - CHANGE  
- [ ] COM 1 (B12) & COM 2/AUDIO PANL (C12) CB - SET  
- [ ] Headset - CHANGE  
  
### Door Open  
  
- [ ] If during takeoff roll:  
    - [ ] Takeoff - ABORT  
- [ ] If in flight:  
    - [ ] Airplane Control - MAINTAIN  
    - [ ] Land as soon as practicable.  
  
### Heated Lift Transducer Malfunction  
  
- [ ] If ice forms on lift transducer vane:  
    - [ ] STALL VANE HEAT (D3) Circuit Breaker - CYCLE  
    - [ ] Probe Heat - CYCLE OFF, ON  
- [ ] If ice remains on lift transducer vane:  
    - [ ] Stall Warning System - EXPECT NO RELIABLE INDICATION  
        - [ ] Impending Stall Warning  
        - [ ] Stall Speed Indication  
        - [ ] Stick Shaker Vibration  
    - [ ] Airspeed - MONITOR, DO NOT STALL  
    - [ ] Fly published VREF Speeds - MINIMUM 88 KIAS W/ 50% FLAPS  
  
### Inadvertent Icing Encounter  
  
- [ ] Probe Heat - ON  
- [ ] Serials w/ IPS: IPS - ON  
- [ ] Exit icing conditions. Turn back or change altitude.  
- [ ] Temperature Selector - HOT  
- [ ] Vent Selector - DEFROST  
- [ ] Airflow Selector - MAXIMUM  
- [ ] Panel Vents - CLOSED  
  
### Inadvertent IMC Encounter  
  
- [ ] Airplane Control - ESTABLISH STRAIGHT AND LEVEL FLIGHT  
- [ ] Autopilot - ENGAGE TO HOLD HEADING AND ALTITUDE  
- [ ] Heading - RESET TO INITIATE 180 DEGREE TURN  
  
### Landing With Failed Brakes  
  
- [ ] One brake inoperative:  
    - [ ] Land on the side of runway corresponding to the inoperative brake.  
    - [ ] Maintain directional control using rudder and working brake.  
- [ ] Both brakes inoperative:  
    - [ ] Divert to the longest, widest runway with the most direct headwind.  
    - [ ] Land on downwind side of the runway.  
    - [ ] Use the rudder for obstacle avoidance.  
    - [ ] Perform Emergency Engine Shutdown On Ground Checklist.  
  
### Landing With Flat Tire  
  
- [ ] Main Gear:  
    - [ ] Land on the side of the runway corresponding to the good tire.  
    - [ ] Maintain directional control with the brakes and rudder.  
    - [ ] Do not taxi. Stop airplane and perform a normal engine Shutdown.  
- [ ] Nose Gear:  
    - [ ] Land in the center of the runway.  
    - [ ] Hold the nosewheel off the ground as long as possible.  
    - [ ] Do not taxi. Stop airplane and perform a normal engine Shutdown.  
  
### Loss of All Flight Displays  
  
- [ ] BAT 1 and BAT 2 Switches - VERIFY ON  
- [ ] ALT 1 and ALT 2 Switches - VERIFY ON  
- [ ] Land as soon as possible.  
  
### Loss of Reliable Airspeed Indication  
  
- [ ] Probe Heat - ON  
- [ ] AP DISC Button - PRESS  
- [ ] AP CTRL (A3) Circuit Breaker - PULL  
- [ ] Land as soon as practicable.  
  
### Loss of Reliable Altitude Indication  
  
- [ ] Alternate Static Source - OPEN  
  
### Windshield IPS Malfunction  
  
- [ ] ICE PROTECT 1 (A4) Circuit Breaker - CYCLE  
- [ ] Fluid Quantity - SWITCH TO FULLER TANK  
- [ ] W/S Push-Button - PRESS AS REQUIRED  
- [ ] If forward field of view is overly restricted during landing, approach, and taxiing:  
    - [ ] Temperature Selector - HOT  
    - [ ] Vent Selector - POSITION  
    - [ ] Airflow Selector - MAXIMUM  
    - [ ] Panel Vents - CLOSED  
    - [ ] Execute a forward slip as required for visibility.  
    - [ ] Avoid taxiing without adequate forward visibility.  
  
### ALTERNATOR 1 CURRENT Caution  
  
- [ ] ALT 1 (D11) Circuit Breaker - SET  
- [ ] ALT 1 Switch - CYCLE  
- [ ] If alternator does not reset:  
    - [ ] ALT 1 Switch - OFF  
    - [ ] Non-Essential Loads - REDUCE  
    - [ ] If flight conditions permit, consider shedding the following to preserve Battery 1:  
        - [ ] Air Conditioning - OFF  
        - [ ] Cabin Fan - OFF  
        - [ ] Landing Lights (LAND Switch) - OFF  
        - [ ] YAW SERVO (C1) Circuit Breaker - PULL  
        - [ ] CONV SYS 1 (D8) Circuit Breaker - PULL  
        - [ ] CONV SYS 2 (D9) Circuit Breaker - PULL  
        - [ ] EVS CAMERA (C5) Circuit Breaker (if installed) - PULL  
    - [ ] Continue Flight, avoiding IMC or night flight as able (reduced power redundancy).  
  
### ALTERNATOR 2 CURRENT Caution  
  
- [ ] ALT 2 (B5) Circuit Breaker - SET  
- [ ] ALT 2 Switch - CYCLE  
- [ ] If alternator does not reset:  
    - [ ] ALT 2 Switch - OFF  
    - [ ] Continue Flight, avoiding IMC or night flight as able (reduced power redundancy).  
  
### AOA FAIL Advisory  
  
- [ ] Low speed red band extends to a fixed value of 61 knots.  
  
### AOA HEAT FAIL Caution  
  
- [ ] STALL VANE HEAT (D3) Circuit Breaker - CYCLE  
- [ ] PITOT HEAT (D2) Circuit Breaker - CYCLE  
- [ ] Icing Conditions - AVOID/EXIT  
  
### BATTERY 1 CURRENT Caution  
  
- [ ] Main Bus 1, 2 and Non-Essential Bus Loads - REDUCE  
    - [ ] Air Conditioning - OFF  
    - [ ] Cabin Fan - OFF  
    - [ ] Landing Lights (LAND Switch) - OFF  
    - [ ] YAW SERVO (C1) Circuit Breaker - PULL  
    - [ ] CONV SYS 1 (D8) Circuit Breaker - PULL  
    - [ ] CONV SYS 2 (D9) Circuit Breaker - PULL  
    - [ ] EVS CAMERA (C5) Circuit Breaker (if installed) - PULL  
- [ ] Main Bus 1, 2 and Essential Voltages - MONITOR  
- [ ] Land as soon as practicable.  
  
### BATTERY 1 FAIL Caution  
  
- [ ] BAT 1 Switch - OFF  
- [ ] Land as soon as practicable.  
  
### BATTERY 1 FAULT Caution  
  
- [ ] BAT 1 Switch - OFF  
- [ ] If message extinguishes:  
    - [ ] BAT 1 Switch - ON  
    - [ ] Continue flight.  
- [ ] If message persists or reoccurs:  
    - [ ] BAT 1 switch - OFF  
    - [ ] Exit IMC as soon as practicable.  
    - [ ] Land as soon as practicable.  
- [ ] Contact Cirrus for corrective action.  
  
### BATTERY 1 LOW Caution  
  
- [ ] If on ground, prior to engine start:  
    - [ ] External Power - CONNECT  
- [ ] If on ground with engine running, or in flight:  
    - [ ] BAT 1 and ALT 1 Switches - VERIFY ON  
    - [ ] Main Bus 1 Voltage - CHECK  
    - [ ] Service aircraft as soon as practicable.  
  
### CHECK OXYGEN Advisory  
  
- [ ] Hypoxia Symptoms - CHECK ALL OCCUPANTS  
- [ ] If hypoxia symptoms suspected:  
    - [ ] Oxygen Mask/Cannula - DON  
    - [ ] Oxygen System (OXY Switch) - ON  
    - [ ] Oxygen Flow Rates - CHECK

### Noise Characteristics/Abatement  
  
- [ ] When operating VFR over noise-sensitive areas, such as outdoor events, parks, and recreational areas, fly not less than 2000 feet above the surface even though flight at a lower level may be allowed.  
- [ ] For departure from or approach to an airport, avoid prolonged flight at low altitude near noise-sensitive areas.

### Serials w/ IPS: If Inadvertent Icing Encounter or Icing Conditions Exist  
  
- [ ] Probe Heat - VERIFY ON  
- [ ] ICE PROTECT System Switch - ON  
- [ ] ICE PROTECT Mode Switch - NORM  
- [ ] W/S Push Button - PRESS (AS REQ'D)  
- [ ] Ice Inspection Lights - AS REQUIRED  
- [ ] Monitor ice accumulation.  
- [ ] If ice accretions persist on protected surfaces following each cycle:  
    - [ ] ICE PROTECT Mode Switch - HIGH  
    - [ ] If ice continues accumulating on protected surfaces:  
        - [ ] ICE PROTECT Mode Push Button - MAX  
        - [ ] If ice accretions do not shed from protected surfaces:  
            - [ ] BKUP Switch - ON  
            - [ ] W/S Push Button - PRESS AS REQUIRED  
            - [ ] Perform Ice Protection System Failure/ Excessive Ice Accumulation.  
            - [ ] Airspeed - MAINTAIN 95-177 KIAS AND LESS THAN 204 KTAS
